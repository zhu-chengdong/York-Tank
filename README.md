# York-Tank

York-Tank is a degradation-aware underwater visual SLAM benchmark dataset collected in a controlled tank environment. It is designed to support systematic evaluation of visual SLAM methods under different dominant degradation conditions and difficulty levels.

The full York-Tank dataset contains 18 stereo visual-inertial sequences covering controlled underwater degradation conditions. The dataset has been completed and is associated with a manuscript currently under review. The full dataset will be released after the paper is accepted.

## Overview

York-Tank provides stereo image sequences, IMU measurements, calibration files, ROS bag files, raw image sequences, and reference trajectories for evaluating underwater visual SLAM systems.

The sequences are organized according to dominant visual degradation factors, including illumination variation, motion-induced degradation, texture deficiency, dynamic disturbance, and hybrid degradation conditions. The benchmark is designed to support degradation-aware and difficulty-stratified evaluation, allowing different SLAM methods to be analysed under controlled and interpretable visual conditions.

## Key Features

* Controlled underwater tank environment
* 18 stereo visual-inertial sequences
* Degradation-aware sequence organization
* Difficulty-stratified evaluation protocol
* Reference trajectories generated by York-Tank-GT
* ROS bag files and raw image sequences for flexible use
* Calibration and evaluation files for SLAM benchmarking

## Current Public Release

The full York-Tank dataset has been completed but is not yet fully public because the associated manuscript is currently under review.

At this stage, we provide **Sequence 1** as a preview release to allow reviewers and interested researchers to inspect the dataset structure, calibration files, ROS bag format, raw image organization, and evaluation-related files.

The preview release is available on Zenodo:

**York-Tank: Preview Release of Sequence 1**  
https://doi.org/10.5281/zenodo.20432375

The preview release includes:

* Raw stereo image files for Sequence 1
* ROS bag file for Sequence 1
* Calibration files
* COLMAP-related files
* Evaluation-related files
* Source data for one paper figure

## Data Organization

The current preview release is organized as follows:

    York-Tank/
    ├── 1_reference1.bag

    ├── colmap.zip
    ├── evaluation.zip
    ├── fig6_source_data.xlsx

Sequence 1 corresponds to the reference condition in the York-Tank dataset. It is provided as a preview release to allow users and reviewers to verify the data format and basic data-loading workflow.
