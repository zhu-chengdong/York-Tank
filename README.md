# York-Tank

York-Tank is a degradation-aware underwater visual SLAM benchmark dataset collected in a controlled tank environment. It is designed to support systematic evaluation of visual SLAM methods under different dominant degradation conditions.

## Overview

The dataset provides stereo image sequences, IMU measurements, and reference trajectories for evaluating underwater visual SLAM systems. The sequences are organized according to dominant visual degradation factors and difficulty levels.

## Key Features

- Controlled underwater tank environment
- Stereo visual-inertial data
- Degradation-aware sequence design
- Difficulty-stratified evaluation
- Reference trajectories from York-Tank-GT
