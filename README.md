# York-Tank

York-Tank is a degradation-aware underwater visual SLAM benchmark dataset collected in a controlled tank environment. It is designed to support systematic evaluation of visual SLAM methods under different dominant degradation conditions and difficulty levels.

## Overview

The dataset provides stereo image sequences, IMU measurements, calibration files, and reference trajectories for evaluating underwater visual SLAM systems. The sequences are organized according to dominant visual degradation factors, including illumination variation, motion-induced degradation, texture deficiency, dynamic disturbance, and hybrid degradation conditions.

York-Tank is designed to support degradation-aware and difficulty-stratified evaluation, allowing different SLAM methods to be analysed under controlled and interpretable visual conditions.

## Key Features

* Controlled underwater tank environment
* Stereo visual-inertial data
* Degradation-aware sequence organization
* Difficulty-stratified evaluation protocol
* Reference trajectories generated by York-Tank-GT
* ROS bag files and raw image sequences for flexible use

## Dataset Release

The York-Tank dataset is being released progressively.

The current initial release provides **Sequence 1** as a representative example for verifying the dataset structure, calibration files, ROS bag format, raw image organization, and evaluation-related files.

The initial release is available on Zenodo:

**York-Tank: Initial Release of Sequence 1**
DOI: https://doi.org/10.5281/zenodo.20432375

The current release includes:

* Raw stereo image files for Sequence 1
* ROS bag file for Sequence 1
* Calibration files
* COLMAP-related files
* Evaluation-related files
* Source data for one paper figure

The remaining sequences, covering different dominant degradation factors and difficulty levels, will be released progressively after final verification.

## Data Organization

The current release is organized as follows:

```text
York-Tank/
├── 1_reference1.bag
├── 1_reference1.zip
├── calibration.zip
├── colmap.zip
├── evaluation.zip
├── fig6_source_data.xlsx
└── LICENSE.txt
```

Sequence 1 corresponds to the reference condition in the York-Tank dataset. It is provided as the first public release to allow users and reviewers to inspect the data format and verify the basic data-loading and evaluation workflow.

## Full Dataset Release Plan

The full York-Tank dataset will include sequences organized by dominant degradation conditions and difficulty levels. Future releases will include illumination, motion, texture, dynamic disturbance, and hybrid degradation sequences.

Planned release stages:

```text
v0.1  Sequence 1, raw files, ROS bag, calibration files, and evaluation-related files
v0.2  Additional representative degradation sequences
v1.0  Full York-Tank dataset release
```
